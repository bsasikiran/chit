# Chit Icon Components — Figma Import Guide

## Recommended import
1. Drag the individual SVG files from `icons/` into a Figma page.
2. Select all imported vectors and create components.
3. Name each component using `Chit / <category> / <icon-name>`.
4. Publish the component page as the **Chit Icons** library.

## Component properties
- `Size`: 16, 20, 24, 32, 40, 48
- `Tone`: Default, Muted, Active, Energy, Climate, Security, Family, Health, Success, Warning, Critical
- `State`: Default, Hover, Disabled

## Figma color variables
- `icon/default`
- `icon/muted`
- `icon/active`
- `domain/energy`
- `domain/climate`
- `domain/security`
- `domain/family`
- `domain/health`
- `state/success`
- `state/warning`
- `state/critical`

Use the source SVGs without backgrounds. Apply color from the component instance or Figma variables.
